## C. 스레드 — 1.1.0 심사 도는 동안 시작

원칙 셋: **완성품 자랑 말고 만드는 과정을 쪼갠다** / 매 글에 스토어 링크 박지 않는다
(3~4번에 한 번, 나머지는 프로필 링크) / **주 3~4회**, 몰아 올리고 사라지지 않는다.

- [ ] **① 출시 글** — 만든 이유. 제일 중요하다.
      > 인터벌 타이머를 하나 만들었습니다. 운동·휴식 시간 맞춰주는 그거요.
      > 쓰던 앱이 구독제로 바뀌어서요. 세트 사이 30초 재는 데 월 결제를 하라는 게
      > 이상해서 직접 만들었습니다. 결제 화면 자체가 없습니다.

- [ ] **② 숫자 공개 글** — 이 계열이 제일 잘 퍼진다.
      > 출시 첫 주 다운로드 0입니다. 여기서 뭐가 어떻게 되는지 계속 적어보겠습니다.

- [ ] **③ 디테일 글** — 음악 볼륨. 1.1.0 작업과 바로 붙는다.
      > 운동앱 타이머 울릴 때마다 듣던 노래가 확 작아지는 거 싫지 않으세요.
      > 그래서 알림음을 노래와 안 겹치는 2~3kHz 대역으로 따로 만들었습니다.
      > 볼륨을 줄이는 대신 그 위에 얹습니다.

- [ ] **④ 기술 글** — 개발자 반응용.
      > 타이머가 화면 꺼진 상태에서도 정확히 울리게 만드는 게 생각보다 어렵습니다.
      > 1초씩 빼면 안 되고, 시작 시각을 붙잡아 두고 매번 다시 계산해야 합니다.
      > iOS는 예약 알림이 64개로 막혀 있어서 그것도 계속 다시 짜야 하고요.

- [ ] **⑤ 영상 글** — 15초, 자막 없이도 통하게.
      폰을 벤치에 엎어놓는다 → 운동한다 → 소리가 난다 → 폰을 든다 →
      화면이 빨강에서 초록으로 바뀌어 있다 → "쉬는 시간 30초. 화면 안 봐도 됩니다."
      **나중에 릴스·쇼츠·영어권에 그대로 재사용된다.**
