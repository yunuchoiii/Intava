# インタバ — ストア掲載情報 (日本語)

機能は [ko.md](ko.md) と同じ — ただし直訳ではなく、日本語検索の習慣に合わせて
キーワードを別に選定した。「宅トレ」「筋トレタイマー」のように日本語圏特有の
検索語があるため。

広告SDK・課金・分析SDKはコードに存在しない — 「広告なし」は事実として書ける。

## アプリが実際にできること

- **完全無料**: 課金・サブスクリプションなし、広告なし — シンプルな機能まで課金で制限するアプリが多いことへの反発から作られたアプリ。今回の最大のセールスポイント。
- **ルーティン**: 複数の種目を順番とラウンド数でつなぎ、実行中は順番に案内
- **タイマー**: 運動・休憩・セットだけを決める単純な反復インターバルタイマー
- **ウォームアップ・準備・クールダウン**
- **バックグラウンド通知**: アプリを完全に終了しても区間の切り替えを音・振動・プッシュ通知で知らせる。音楽再生中も音量を下げずに通知音を重ねて再生
- **運動記録**: 月カレンダー、合計時間・純運動時間・完了セット/ラウンド、完走/中断の表示
- **ローカル完結**: ログイン不要、サーバー送信なし、書き出し・読み込みでバックアップ・機種変更
- **ダークUI**、多言語対応(韓/英/日/中)

存在しない機能(AIコーチ、クラウド同期など)は書かない。

## App Store (iOS)

### 名前 (30文字制限)
```
Intava - 無料インターバル運動タイマー
```

### サブタイトル (30文字制限)
```
タバタ・サーキット・ルーティンタイマー
```

### キーワード欄 (100文字制限、カンマ区切り・スペースなし — 名前/サブタイトルの単語は繰り返さない)
```
無料,セット,ラウンド,筋トレ,宅トレ,家トレ,自重,HIIT,有酸素,ストップウォッチ,カウントダウン,休憩,運動記録,広告なし,ログイン不要,体幹,ダイエット,スクワット
```

### プロモーションテキスト (170文字制限 — 審査なしでいつでも変更可能)
```
完全無料です。画面を見なくても大丈夫、音と振動が区間の切り替えを知らせるので、スマホを置いて運動に集中できます。ルーティンとタイマー、運動記録まで全部インタバで。広告なし、課金なし。
```

### 説明文 (4000文字制限 — 最初の3行が「もっと見る」の前に表示される最重要部分)
```
完全無料の運動タイマー、インタバ。

シンプルなインターバルタイマーの機能まで課金やサブスクリプションで制限するアプリが多かったので、そういう壁のないタイマーを自分で作りました。インタバはどの機能も課金で制限しません。

音と振動が区間の切り替えを知らせるので、スマホを置いて運動に集中できます。アプリを完全に終了していても通知は届きます。

■ ルーティン — 複数の種目を順番に
スクワット、プランク、バーピーなどの種目を好きな順番とラウンド数でつなげておけば、次に何をするか画面を見なくても案内してくれます。

■ タイマー — 運動・休憩・セットを決めるだけ
タバタ、HIIT、サーキットトレーニングのように、ひとつの動きを繰り返すシンプルなインターバルタイマーです。

■ ウォームアップ・準備・クールダウン
本運動の前後に体をほぐし、整える時間も同じ流れの中でつながります。

■ バックグラウンドでも途切れない通知
アプリを完全に終了していても、区間が切り替わるたびにプッシュ通知・音・振動で知らせます。音楽を聴いていても音量を下げずに通知音だけ重ねて再生します。

■ 運動記録
月カレンダーで運動した日を一目で確認でき、合計時間・純運動時間・完了したセット数もわかります。

■ 完全無料・広告なし・ログイン不要
課金もサブスクリプションもありません。アカウント登録も不要です。すべてのデータは端末内だけに保存され、機種変更のときは書き出し・読み込みで移行できます。

こんな方におすすめ
- ジムや宅トレでスマホの画面をずっと見ていたくない方
- タバタ・HIIT・サーキットトレーニングを自分で組み立てたい方
- 運動記録を残したいけれど、複雑なアプリは負担に感じる方
- シンプルな機能まで課金で制限するタイマーアプリに疲れた方

画面ではなく運動に集中する — インタバと一緒に。
```

## Google Play (Android)

Playには専用のキーワード欄がなく、タイトル・簡単な説明・詳しい説明が直接ランキングに影響する。
App Storeの文章より少しキーワードの反復密度を上げる。

### タイトル (30文字制限)
```
Intava - 無料インターバル運動タイマー
```

### 簡単な説明 (80文字制限)
```
完全無料のインターバルタイマー。広告・課金なし、音と振動でタバタ・サーキットを案内、運動記録も。
```

### 詳しい説明 (4000文字制限)
```
完全無料のインターバル運動タイマー、インタバ。

シンプルなインターバルタイマーの機能まで課金やサブスクリプションで制限するアプリが多かったので、そういう壁のないタイマーを自分で作りました。課金もサブスクリプションも広告もありません。

インタバは音と振動で運動区間の切り替えを知らせるタイマーアプリです。タバタ、HIIT、サーキットトレーニングのような反復運動をするとき、スマホの画面をずっと見ていなくても、音と振動だけで次の区間がわかります。アプリを完全に終了していてもバックグラウンド通知で区間の切り替えを逃しません。

■ ルーティン — 種目を順番とラウンドで
スクワット、プランク、ランジ、バーピーなどの種目を好きな順番とラウンド数でつなげておけば、実行中は次の種目まで自動で案内します。サーキットトレーニングや全身運動ルーティンを組むときに特に便利です。

■ タイマー — 運動・休憩・セットを決めるだけ
タバタタイマー、HIITタイマーのように、ひとつの動きを決めた時間・セット数で繰り返すシンプルなインターバルタイマーです。

■ ウォームアップ・準備・クールダウン
本運動の前後に体をほぐし整える時間も、同じ流れの中でつながります。

■ バックグラウンド通知
アプリを完全に終了していても、運動・休憩の区間が切り替わるたびにプッシュ通知・音・振動で知らせます。音楽を聴いている間も音量を下げずに通知音だけ重ねて再生します。

■ 運動記録
月カレンダーで運動した日を一目で確認でき、合計時間・純運動時間・完了したセット数とラウンド数がわかります。

■ 完全無料・広告なし・ログイン不要
会員登録もログインも、課金もサブスクリプションもありません。すべてのルーティン・タイマー・運動記録は端末内だけに保存され、サーバーには送信されません。機種変更やバックアップが必要なときは、書き出し・読み込み機能でファイル1つにまとめて移行できます。

こんな方におすすめ
- ジムや宅トレでスマホの画面をずっと見ていたくない方
- タバタ・HIIT・サーキットトレーニングを自分でセットとラウンドから組み立てたい方
- 自重トレーニングのルーティンを繰り返し管理し、運動記録を残したい方
- シンプルな機能まで課金で制限するタイマーアプリに疲れた方

インターバルタイマー、タバタタイマー、サーキットタイマー、宅トレタイマー — インタバひとつで十分です。
```
