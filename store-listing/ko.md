## 앱이 실제로 하는 일 (문구의 근거)

- **완전 무료**: 과금 유도 없음(IAP·구독 없음), 광고 없음 — 간단한 기능도 유료로 막는 앱이 많아서 직접 만든 앱. 이게 이번 셀링포인트의 핵심이다.
- **루틴**: 종목 여러 개를 순서·라운드로 엮어 실행 중 순서대로 안내
- **타이머**: 운동·휴식·세트만 정하는 단순 반복 인터벌 타이머
- **웜업·준비·쿨다운**
- **백그라운드 푸시**: 앱을 완전히 꺼도 구간 전환을 알림·소리·진동으로 전달, 음악 위에 볼륨 안 줄이고 겹쳐 재생
- **운동 기록**: 월 캘린더, 총 시간·순수 운동 시간·완료 세트/라운드, 완주/중단 표시
- **로컬 전용**: 로그인 없음, 서버 전송 없음, 내보내기/불러오기로 백업·기기 이동
- **다크 UI**, 다국어(한/영/일/중)

과장 금지 — "AI", "개인 트레이너", "무제한 클라우드 동기화" 같은 실제로 없는 기능은 쓰지 않는다.

```
홈트,세트,라운드,웨이트,HIIT,헬스,다이어트,맨몸운동,유산소,알람,스트레칭,카운트다운,근력,코어,전신,스쿼트,버피,휴식,반복,체력,타바타,무료,무광고,크로스핏,줄넘기,스톱워치
```

```
잠금화면과 다이내믹 아일랜드에서 남은 시간과 다음 순서를 바로 볼 수 있어요. 광고, 결제, 로그인 없이 모든 기능을 무료로 쓸 수 있습니다.
```

### 스크린샷 순서 (지금)
1. 운동에만 집중하세요 2. 어디서나 이어지는 타이머 3. 운동 순서까지 알아서 4. 내 운동에 딱 맞게
5. 운동 중에도 자유롭게 6. 운동 기록 한눈에 7. 필요한 기능, 모두 무료

### 1.5.2에 바꿀 초안

키워드와 부제는 새 버전을 낼 때만 바뀐다. 근거는 2026-10-27 분석: 9/26~10/25 최초 다운로드 278건 중
274건이 App Store 검색이었다. 유입이 사실상 검색 하나다.

- **키워드** (98자)
  ```
  운동,홈트레이닝,홈트,세트,라운드,웨이트,HIIT,헬스,다이어트,맨몸운동,유산소,스트레칭,카운트다운,근력,코어,전신,스쿼트,버피,휴식,체력,무료,크로스핏,EMOM,줄넘기,스톱워치
  ```
  - 뺀 것: 「타바타」(이름에 있음), 「알람」「반복」(검색어로 약함), 「무광고」(부제의 「광고」와 겹침)
  - 넣은 것: 「운동」「홈트레이닝」「EMOM」
- **부제**: `광고·결제 없는 운동 루틴·서킷 기록`
  - 「운동기록」으로 붙어 있으면 「운동 타이머」 검색에 「운동」이 따로 안 잡힐 수 있다고 봤다. Apple이 한국어 복합어를 어떻게 쪼개는지는 확인하지 못한 추정이다.
- **스크린샷**: 7번 「필요한 기능, 모두 무료」를 3번으로 당긴다. 검색 결과 카드에는 앞 3장만 보이는데, 무료가 핵심 차별점이다. 스크린샷은 버전과 무관하게 바꿀 수 있다.

## Google Play (Android)

Play는 별도 키워드 필드가 없다 — 제목 · 짧은 설명 · 자세한 설명 안에서 키워드가 직접 랭킹에 영향을 준다. 자연스러운 범위에서 App Store보다 반복 밀도를 조금 높인다.

### 제목 (30자 제한)
```
인타바 - 무료 인터벌 타이머
```

### 짧은 설명 (80자 제한)
```
완전 무료 인터벌·타바타·서킷 타이머 — 광고·결제 없이, 소리·진동 안내와 운동 기록까지.
```

### 자세한 설명 (4000자 제한)
```
완전 무료 인터벌 운동 타이머, 인타바.

간단한 인터벌 타이머 기능마저 구독이나 결제로 막아두는 앱이 많아서, 그런 벽 없이 쓸 수 있는 타이머를 직접 만들었습니다. 광고도 없고, 어떤 기능도 유료로 막지 않습니다.

인타바는 소리와 진동으로 운동 구간을 알려주는 타이머 앱입니다. 타바타, HIIT, 서킷 트레이닝처럼 반복하는 운동을 할 때 폰 화면을 계속 들여다보지 않아도, 다음 구간이 언제 시작되는지 소리와 진동만으로 알 수 있습니다. 앱을 완전히 종료해도 백그라운드 알림으로 구간 전환을 놓치지 않습니다.

■ 루틴 — 종목을 순서와 라운드로
스쿼트, 플랭크, 런지, 버피 같은 종목을 원하는 순서와 라운드 수로 엮어두면, 실행할 때 다음 종목까지 자동으로 안내합니다. 서킷 트레이닝, 전신 운동 루틴을 짤 때 특히 유용합니다.

■ 타이머 — 운동 · 휴식 · 세트만 정하면 끝
타바타 타이머, HIIT 타이머처럼 한 동작을 정해진 시간 · 세트로 반복하는 단순한 인터벌 타이머입니다.

■ 웜업 · 준비 · 쿨다운
본운동 앞뒤로 몸을 풀고 정리하는 시간까지 하나의 흐름으로 이어집니다.

■ 백그라운드 알림
앱이 완전히 꺼져 있어도 운동 · 휴식 구간이 바뀔 때마다 푸시 알림 · 소리 · 진동으로 알려줍니다. 음악을 듣는 중에도 볼륨을 줄이지 않고 알림음만 겹쳐 재생합니다.

■ 운동 기록
월 캘린더에서 운동한 날을 한눈에 보고, 총 시간 · 순수 운동 시간 · 완료한 세트와 라운드를 확인할 수 있습니다.

■ 완전 무료 · 광고 없음 · 로그인 불필요
회원가입이나 로그인이 없습니다. 결제나 구독으로 막힌 기능도 없습니다. 모든 루틴 · 타이머 · 운동 기록은 기기 안에만 저장되며, 서버로 전송되지 않습니다. 기기를 바꾸거나 백업이 필요할 땐 내보내기 · 불러오기 기능으로 파일 하나로 옮길 수 있습니다.

이런 분께 추천합니다
- 헬스장 · 홈트에서 폰 화면을 계속 보고 싶지 않은 분
- 타바타 · HIIT · 서킷 트레이닝을 세트와 라운드로 직접 구성하고 싶은 분
- 맨몸운동 루틴을 반복 관리하고 운동 기록을 남기고 싶은 분
- 간단한 기능을 유료로 막아두는 타이머 앱에 지친 분

인터벌 타이머, 타바타 타이머, 서킷 타이머, 홈트 타이머 — 인타바 하나로 충분합니다.
```

## 뺀 키워드 (검토했지만 안 쓴 것)

- **"AI", "코칭", "개인 트레이너"** — 앱에 없는 기능. 리뷰·평점에서 역효과.
- **"클라우드", "동기화"** — 의도적으로 로컬 전용으로 설계했다([[intava-next-work]] 참고). 반대되는 키워드는 오해를 부른다.
- **"명상", "요가"** — 인터벌 구조가 맞지 않는 카테고리라 유입돼도 이탈률만 높인다.
