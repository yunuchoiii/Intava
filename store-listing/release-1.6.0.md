# 1.6.0 — 스토리 공유 카드

새 기능(공유 카드 네 가지 + 카드 고르기 화면)이 들어가 1.5.3이 아니라 1.6.0이다(2026-11-03 사용자 결정).
App Store Connect에서 1.6.0 버전을 만들 때 앱의 기본 언어를 영어(미국)로 바꾼다 — 출시된 판만 있을 땐 잠겨 있었다.

## 이번 버전의 새로운 기능

### 한국어
```
이번 업데이트에서는 운동 기록을 공유하는 카드를 새로 만들었습니다. 오운완 사진 위에 기록을 얹거나, 다섯 가지 카드 중 마음에 드는 스타일을 골라 바로 공유할 수 있어요.

새로 추가했어요
- 사진 위에 운동 기록을 얹는 공유 카드
- 다섯 가지 카드 스타일 중에서 골라 공유하는 기능

이런 점도 개선했어요
- 운동 기록에서 공유하기를 누르면 바로 카드를 고를 수 있어요.
- 잠금화면과 다이내믹 아일랜드 타이머가 앱과 같은 시각에 넘어가요.

인타바는 이번에도 구독, 광고, 로그인 없이 무료로 사용할 수 있습니다.
```
