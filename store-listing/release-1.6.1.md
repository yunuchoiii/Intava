# 1.6.1 — 새 사용자에게도 공유 카드 팝업

1.6.0은 온보딩을 마칠 때 새 기능 팝업을 본 것으로 적어, 새로 설치한 사람에게 공유 카드 소개가 뜨지 않았다. 공유 카드는 온보딩이 소개하지 않으므로 잘못이다(사용자 지적 2026-11-04).

## 이번 버전의 새로운 기능

### 한국어
```
이번 업데이트에서는 새로 설치한 분들도 공유 카드 소개를 볼 수 있도록 고쳤습니다.

이런 점도 개선했어요
- 처음 설치한 뒤 시작 화면을 마치면 새 공유 카드 소개가 나와요.

인타바는 이번에도 구독, 광고, 로그인 없이 무료로 사용할 수 있습니다.
```

### English
```
This update makes sure new users also see the introduction to share cards.

Improved
- After finishing setup on a fresh install, you now see the introduction to the new share cards.

Intava is still free, with no subscription, no ads and no login.
```
